البطاقة المطبوعة للعميل: ورق عاجي، زخارف ذهبية، والاسم بخط عربي ذهبي.

## اللغتان

الدعوة بالعربية افتراضياً، وزر **EN / ع** أعلى الصفحة يبدّل إلى الإنجليزية
(اتجاه LTR وخطوط لاتينية). كل النصوص بلغتيها في ملف `i18n.js`.

## أقسام الصفحة

1. **الظرف المختوم** — اضغط الختم الذهبي: يطير الختم، يُفتح الغطاء،
   وتخرج البطاقة من الظرف، ثم تدخل الصفحة مع نثار ذهبي.
2. **الدعوة** — النص كما في بطاقة العميل، والاسم بخط ذهبي كبير.
3. **الموعد والمكان** — بطاقتان.
4. **برنامج السهرة** — الفترتان.
5. **العدّ التنازلي** + زر «أضف الموعد للتقويم» (جوجل / أوتلوك / آبل).
6. **الوصول** — زر يفتح موقع الديوان على خرائط جوجل.
7. **المشاركة** — زر مشاركة النظام، وزر نسخ الرابط.

## كيف تعدّل المعلومات

- **الأسماء والنصوص:** `index.html` — كل النصوص ظاهرة مباشرة.
- **التاريخ والوقت والمكان ورابط الخريطة:** `script.js` في كتلة `CONFIG`
  أعلى الملف. ⚠️ الشهور تبدأ من صفر: `7` تعني آب.
  التاريخ مكتوب في مكانين: `CONFIG` (للعدّاد والتقويم) وفي `index.html`
  (للعرض) — حدّثهما معاً.
- **الألوان والخطوط والمسافات:** `theme.css` فقط.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو:

```bash
python3 -m http.server 4321
```

ثم افتح `http://localhost:4321`.

## ملاحظات

- الصفحة تعمل بلا إنترنت باستثناء الخطوط (Google Fonts).
- تدعم `prefers-reduced-motion`: تُلغى الحركة والنثار لمن يطلب ذلك.
- «إضافة إلى الشاشة الرئيسية» على iPhone تفتحها بملء الشاشة بلا شريط Safari.
